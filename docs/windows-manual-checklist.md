# Windows 真机验证清单

> 本清单覆盖 CI 与单测无法自动化的真机环节（实机打印机、扫码枪、安装体验、手动备份）。
> 每项含**操作步骤 / 预期结果 / 勾选框**，逐项执行并勾选。
> 适用版本：v0.3.0；安装包来源：GitHub Releases（tag `v0.3.0` 自动构建发布，文件名 `销存系统-0.3.0-setup.exe`）。

## 准备

- 一台 Windows 10/11 x64 电脑（管理员账户）
- 热敏小票打印机一台（USB 或网口，已通电）
- 扫码枪一支（HID 键盘模拟型，USB 即插即用）
- 从 CI 下载的安装包 `销存系统-0.3.0-setup.exe`

## 1. 安装与首次启动（首启建库）

**操作步骤**

1. 双击 `销存系统-0.3.0-setup.exe`
2. 安装向导为中文界面；允许选择安装目录（默认 `C:\Users\<用户名>\AppData\Local\Programs\销存系统`）
3. 完成安装并从桌面/开始菜单启动「销存系统」
4. 打开资源管理器进入 `%APPDATA%\selling-electron\`（地址栏直接粘贴回车）

**预期结果**

- [ ] 安装向导全程中文，可更改安装目录
- [ ] 启动后出现应用主窗口（左侧菜单：收银台/商品管理/进货管理/销售记录/报表/模板编辑/设置）
- [ ] `%APPDATA%\selling-electron\pos.db` 文件存在（首启自动建库，含全部数据表）
- [ ] 再次双击启动不出现第二个窗口（单实例锁生效，已有窗口被聚焦）

## 2. 系统打印机列表可见

**操作步骤**

1. 进入「设置」页
2. 查看「打印机」下拉框
3. 对照 Windows「控制面板 → 设备和打印机」中的已安装打印机列表

**预期结果**

- [ ] 下拉框列出与系统一致的打印机清单，小票打印机名称出现在列表中
- [ ] 列表内容与 Windows 设备和打印机页面一致（多/少打印机均异常）

## 3. spooler 通道测试打印

**操作步骤**

1. 设置页「打印通道」选择 `spooler`，「打印机」选择小票打印机
2. 点击「测试打印」按钮
3. 观察打印机出纸情况

**预期结果**

- [ ] 打印机出一张小纸条，内容居中显示 `test`，随后自动切纸
- [ ] 应用无报错弹窗（打印失败会出现含"打印失败"字样的错误提示）

**若乱码 / 空走纸 / 打印图形化内容**：小票机驱动把原始字节当作图形渲染了，需安装
Generic/Text Only 驱动建立 RAW 通道：

1. 控制面板 → 设备和打印机 → 添加打印机 → 「我需要的打印机不在列表中」
2. 选择对应端口（USB 口选 `USB001`/`USB002`；网口选「添加 TCP/IP 端口」填打印机 IP）
3. 厂商选 `Generic`，打印机选 `Generic / Text Only`，完成安装
4. 回到设置页，打印机下拉选择新建的 `Generic / Text Only`，重新点击「测试打印」
5. [ ] 修复后按上述预期出纸切纸

### 云「外卖」打印机（得力 DL-5801PW 等）：spooler 打得出英文、中文/Logo 不出 → 切 driver 通道

> 背景：这类「云」打印机的固件把 RAW 通道载荷当 UTF-8 文本渲染——GBK 中文双字节
> 被静默丢弃、光栅图片指令不被执行（英文恰好能出，症状极具迷惑性）；但同一台机器
> 走 Windows 打印机驱动渲染（Word 打印的同一条路径）中文与图片都正常。应用已内置
> **driver 驱动渲染通道**（收据渲染成 HTML → 系统驱动光栅化）作为此类机型的兜底。

**操作步骤**

1. 设置页「打印通道」选择 `driver`（驱动渲染），「打印机」选择该云打印机
2. 点击「测试打印」
3. 重复第 4 项的结账 → 预览 → 打印全流程一次

**预期结果**

- [ ] 测试打印出纸：中文、Logo（已上传时）全部正常，版式与预览一致
- [ ] 结账小票实纸内容与预览一致（中文/对齐/倍高倍宽/粗体/Logo 逐项核对）
- [ ] driver 通道无自动切纸指令（驱动渲染页高按内容自适应；裁切位置以纸面剪切示意线为准）
- [ ] 打印速度略慢于指令直发属正常（驱动渲染整页位图）

## 4. 真实结账 → 预览 → 打印（全要素检查）

**操作步骤**

1. 「商品管理」新增 2~3 个商品（含条码、名称、售价）
2. 「设置」页填写店铺名称/电话（长一点，如 6 字以上店名），需要 Logo 的在此上传 PNG Logo
3. 「收银台」双击或扫码加入商品 → 修改数量/单价 → 点击结账
4. 结账后弹出小票预览窗口，核对预览内容，点击「立即打印」

**预期结果**

- [ ] 预览窗口显示完整小票（店铺名、单号 `yyyyMMdd-NNNN`、日期时间、商品行、合计、谢幕语）
- [ ] 实纸打印内容与预览一致，逐项核对：
  - [ ] 中文全部正常（无乱码方块）
  - [ ] 店铺名称为**倍高/倍宽**显示
  - [ ] 店铺名称/电话**居中**对齐
  - [ ] 合计行为**粗体**
  - [ ] 打印完成后**自动切纸**
  - [ ] 已上传 Logo 时纸面顶部出现 Logo 图案（未上传则跳过此项）
- [ ] 打印失败时销售不丢失：弹窗提示"销售已保存，可稍后在销售记录中重打"

## 5. tcp 通道（打印机有网口时执行，无网口跳过）

**操作步骤**

1. 查看打印机网口 IP（打印机自检页通常可打印出 IP）
2. 设置页「打印通道」选 `tcp`，主机填打印机 IP，端口默认 `9100`
3. 点击「测试打印」
4. 重复第 4 项的结账 → 预览 → 打印全流程一次

**预期结果**

- [ ] 测试打印经网络到达打印机，出纸内容与第 3 项预期一致
- [ ] 结账打印全流程在 tcp 通道下同样正常（中文/格式/切纸一致）
- [ ] 拔掉网线后再打印：应用报错提示打印失败，但销售记录与库存不受影响

## 6. 扫码枪实枪加购（中文输入法开启状态）

**操作步骤**

1. 确认系统输入法切换到**中文输入法**（如微软拼音）状态
2. 光标停留在收银台扫码输入区域
3. 用扫码枪依次扫 5 个不同真实商品条码（商品需已录入且有条码）
4. 对同一商品快速连扫 2 次

**预期结果**

- [ ] 每次扫码后对应商品立即加入购物车，无人工干预
- [ ] 商品名含中文的行正常显示，数量/单价/小计正确
- [ ] 同一条码连扫两次：同一行数量 +1（合并行，不新增行）
- [ ] 全程无输入法候选框吞掉扫描字符的现象

## 7. 连续快速结账（打印串行不交叠）

**操作步骤**

1. 保持打印通道可用（spooler 或 tcp）
2. 连续完成 3 笔结账，每笔结账后立即（不等打印完成）开始下一笔扫码/结账
3. 收集 3 张打印出的小票

**预期结果**

- [ ] 3 张小票独立完整，每张内容互不交叠、互不串字节（无半张 A 单 + 半张 B 单）
- [ ] 单号连续（如 `0001`、`0002`、`0003`）
- [ ] 3 张小票的商品内容与各自订单逐一对应
- [ ] 结账操作全程无卡顿等待（打印异步进行，不阻塞收银）

## 8. 生僻字商品打印（GBK 降级）

**操作步骤**

1. 新增一个商品，名称填入 `𠀀𡈽测试`（含 GBK 外生僻字）；另一个商品名称填入 `龘龘商品`
2. 两个商品分别结账打印（或加入同一单打印）

**预期结果**

- [ ] GBK 外生僻字（`𠀀𡈽`）在小票纸上显示为 `?`（如 `??测试`），**应用不崩溃、结账不失败、打印流程正常完成**
- [ ] GBK 内生僻字（`龘`，属 GBK 字符集）正常打印汉字，不降级
- [ ] 销售记录页查看该单：商品名显示完整原文（降级只发生在打印编码层，不污染库存数据）

## 9. 数据备份（手动）

**操作步骤**

1. 完全关闭应用（右上角 × 退出，确认托盘/后台无残留进程）
2. 打开 `%APPDATA%\selling-electron\` 目录
3. 观察 pos.db 附近的 WAL 文件；完整复制 `pos.db`、`pos.db-wal`、`pos.db-shm` 三个文件（若 -wal/-shm 不存在，仅复制 pos.db）到备份位置
4. （验证备份）将备份的 pos.db 复制到另一台电脑的同位置（或还原本机），启动应用查看商品/销售记录

**预期结果**

- [ ] 应用关闭后数据目录中 `pos.db` 存在且可复制（不被进程占用锁定）
- [ ] 备份文件还原后启动应用，商品/销售记录/报表数据完整可见
- [ ] 恢复后可正常继续收银结账（新单写入无异常）
