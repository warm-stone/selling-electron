=== S2 spike 备注：Electron 44 二进制下载机制变更（重要） ===
现象：npm install 后首次 `npm run dev` 报 `Error: Electron uninstall`（electron-vite 直读 node_modules/electron/path.txt）
根因：Electron ≥44 的 npm 包已移除 postinstall（npm view electron@44 scripts 为空，32.x 时代才有 postinstall），
      改为按需下载：node_modules/.bin/install-electron（幂等，已装则 exit 0）。
      electron-vite 只读 path.txt 不触发 electron/index.js 的懒下载 → 二进制缺失。
修复：package.json 增加 "postinstall": "install-electron" —— npm ci / npm install 后自动补齐（幂等）。
本机验证：手动 node install.js 下载 v44.10.1 成功；postinstall 复跑 EXIT=0。
结论：S2 spike 通过 —— electron-vite 6.0.0（vite 8.3.5 rolldown 链）+ Vue 3.5.44 + TS 5.9.3 + Element Plus 2.14.7 dev/build 均正常，无需 fallback 到 electron-vite 5。
