## 2. workflow 结构（3 job 设计）
- job1 test（windows-latest）：checkout → setup-node(22,cache npm) → npm ci → typecheck → vitest → E2E
  * 保持 Task 1/6 建立的现有 steps 原样（任务约束：不得破坏现有 test job）
  * postinstall=install-electron 随 npm ci 自动补二进制（未画蛇添足加下载步骤）
  * E2E=npm run test:e2e：windows-latest 自带桌面会话无 xvfb；globalSetup 内部执行 npm run build
  * _electron 用应用自带 Electron 二进制，workflow 无 playwright install 浏览器下载（任务约束）
- job2 build（needs: test, windows-latest）：checkout → setup-node → npm ci → npm run build（electron-builder 需现成 out/）
  → npx electron-builder --win nsis → upload-artifact@v4（name=windows-nsis-installer,
    path=release/*.exe, if-no-files-found: error）
  * win32 上零 wine 依赖（app-builder-lib WineVm.js 源码：process.platform==='win32' 直通 exec）
  * npmRebuild=false 免 VS 源码编译（better-sqlite3 v13 N-API prebuilds，S1 spike）
- job3 linux-check（ubuntu-latest）：npm ci → npm test（vitest 全量；G11 双平台验证，轻量 job）
